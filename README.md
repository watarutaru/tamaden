# たま電 プログラムページ

身内向け音楽イベント「たま電」当日用の、スマホで見るプログラム表（縦スクロール1枚）。

## 設置方法（ホスティング）

`index.html` **1ファイルだけ** で完結しています。サーバーの好きな場所に置けばそのまま表示できます。

- 例: `https://example.com/tamaden/` で見せたい場合 → そのディレクトリに `index.html` を置くだけ
- 外部依存はGoogle Fonts（`fonts.googleapis.com`）のCDN読み込みのみ。画像・アイコン・ロゴはすべてHTML内に埋め込み済み（追加ファイル不要）

## 中身を編集したいとき

- **文言・出演者**: `index.html` の該当箇所（`<section>` や `.row`）を直接書き換え
- **背景色など**: `<style>` 冒頭の `:root{ --bg: ... }` の変数を変更
- **Discordリンク**: `<script>` 内の `GUILD` / `CHANNEL` のID、および `#discord` の `href`
- **地図リンク**: `AFTER PARTY` の `.mapbtn` の `href`

## メモ

- スマホファースト。画面幅が広いPCでは中央に402px幅で表示されます。
- ヘッダーの GAIN / PRESSURE のツマミは、ドラッグ/スワイプで回せる飾りです（動作には影響しません）。
- Discordボタンはスマホでアプリを優先的に開き、未インストール等の場合はブラウザ版へ切り替わります。
